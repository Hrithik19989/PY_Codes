Once the basics work, stretch yourself with these:

Due dates — add a "due" field, and warn when tasks are overdue in list_tasks()
Priorities — add "priority": "high/medium/low" and sort by it in the list
Filter flags — python todo.py list --pending to show only incomplete tasks
Colors — install rich (pip install rich) and use colored output for done/pending
Tests — write test_todo.py using unittest to test each function
